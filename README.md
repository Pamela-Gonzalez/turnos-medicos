# API REST - Sistema de Turnos Médicos 🩺

API REST desarrollada con **Node.js**, **Express** y **TypeScript** para la gestión de profesionales médicos y especialidades. Proyecto configurado para ejecutarse en entorno de desarrollo con `tsx`.

---

* Tecnologías Utilizadas

* **Node.js** (Entorno de ejecución)
* **Express** (Framework de servidor)
* **TypeScript** (Lenguaje principal)
* **tsx** (Ejecutor de TypeScript en desarrollo)
